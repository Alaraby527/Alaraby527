## 项目成熟度说明

- **实际投入使用**：有明确使用对象或实际业务场景
- **独立重做**：基于真实业务认知重新设计和实现
- **独立原型**：完成核心流程和评测，但不等同于生产上线
- **模拟评测**：使用模拟数据验证方案和迭代方向
- **学习沉淀**：方法论、Skill、模板或课程资料

部分学习资料和个人工具为私有仓库，面试交流时可按需说明。
